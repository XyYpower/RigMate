## 二、关键字段说明

### 通用
| 字段 | 含义 |
| --- | --- |
| `id` | 唯一键。**已加类目前缀**（`amd-`/`int-`/`gpu-`/`mb-` 等），跨类目唯一 |
| `name_cn` | 官方中文名。AMD CPU 用「锐龙9 9950X3D」；**显卡保持英文型号**（大陆直接说"5090"） |
| `aliases` | 检索别名，覆盖大陆用户实际输入写法 |
| `tier` / `perf_score` | 档位 1–10 / 相对性能分（**定序用，非跑分原值**） |
| `note` | 避坑说明，`⚠️` 标记必须注意 |
| `price_tier` | 价格档位（不含具体价格） |
| `null` | 未查到官方数据，**未做推测填充** |

### 各部件核心约束字段
| 部件 | 核心字段 | 关键提示 |
| --- | --- | --- |
| CPU | `ptp_max`、`m2_lanes`、`has_igpu`、`x3d`、`socket` | ⚠️ 散热按 **ptp_max** 不是 tdp；33 个型号 m2_lanes 仅 2 路；51 个无核显 |
| 显卡 | `length_mm`、`tgp_w`、`power_conn`、`vram_gb`、`bandwidth_gbps`、`china_only` | ⚠️ 5 个超长 >330mm；5 个中国特供；16pin 供电需求 |
| 主板 | `socket`、`ddr`、`dimm_slots`、`m2_slots`、`vrm_score`、`formfactor` | ⚠️ `vrm_score` = 相数×安数，范围 400–2860 **差 7 倍**；15 个仅 2 槽 |
| 内存 | `ddr`、`sticks`、`speed_mt`、`cl`、`height_mm` | ⚠️ `height_mm` ≥44mm 与双塔风冷冲突 |
| 固态 | `pcie_gen`、`dram_cache`、`tbw` | ⚠️ `dram_cache` 含"无缓存"者大文件写入掉速 |
| 电源 | `watt`、`atx`、`pcie12v2x6`、`length_mm` | ⚠️ ATX 3.1 才有完整瞬时保护；6 个 ≥200mm 仅全塔可装 |
| 散热 | `height_mm`、`dissipation`、`sockets` | ⚠️ `sockets` 必须含 CPU socket，**官网未列的不代表支持** |
| 机箱 | `gpu_max_len`、`cooler_max_height`、`rad_support`、`psu_max_len` | ⚠️ 限长标注口径不一（含供电头/不含） |

## 三、整机峰值功耗估算

```
峰值 = CPU.ptp_max + GPU.tgp_w + 60（主板） + RAM.sticks×5
     + 固态数量×7 + (水冷35 | 风冷8) + 5×4（机箱风扇）

电源选择：峰值 × 1.25 ≤ psu.watt ≤ 峰值 × 2.20
```

## 四、必须知道的硬件陷阱

### 4.1 跨类目高危（会导致直接装不上）

| 陷阱 | 影响型号数 | 说明 |
| --- | --- | --- |
| **CPU 无核显必须配独显** | 51 个 | 全部 F/KF 后缀 + AMD 全系 |
| **CPU M.2 通道仅 2 路** | 33 个 | 8000G 全系 + AM4 全系；主板插槽够但 CPU 通道不够 |
| **主板仅 2 个内存槽** | 15 个 | 含 3 个 ATX 大板（技嘉钛雕、华硕 ROG MAXIMUS Z890 APEX 为极限内存频率牺牲） |
| **LGA1700 主板 DDR4/DDR5 双版本** | 10 组 | 微星 MAG B760 TOMAHAWK WIFI 与 ...DDR4 仅差末尾几字，插槽完全不通用 |
| **风冷缺 LGA1851 扣具** | 已核实 7 款 | **德静界 Dark Rock 3 官网最高仅 LGA1200**（连 LGA1700 都没有）；Pure Rock 2 最高 LGA1700；九州 LE520/LE720 最高 LGA1700；**NZXT 旧 X 系列出厂不含 LGA1700 扣具**，装 LGA1851 须另购 |
| **机箱限高 <150mm** | 8 个 | 极端值乔思伯 N2 仅 65mm、NR200P MAX 67mm；安钛克 P5 155mm / 酷冷 Q300L 159mm 装不下猫头鹰 NH-D15（165mm） |

### 4.2 中国特供型号（5 个显卡 + 9 个 CPU）

| 型号 | 与海外版差异 |
| --- | --- |
| **RTX 5090D V2** | ⚠️⚠️ CUDA 相同但**显存 24GB（vs 32GB）、带宽缩水 25%**，价格相同 |
| RTX 5090D | 显存不缩水，仅 AI 算力限 2375 TOPS |
| RTX 4090D | 显存不缩水，CUDA −11% |
| RX 9070 GRE | 相比 9070 缩水 32.5% |
| RX 7900 GRE | 相比 7900 XT 缩水 28% |
| i5-12490F / 12490 | 中国特供，注意 Boost 规格与常规 12400F 不同 |
| i5-13490F / 13490 | 中国特供 |
| i5-14400F / 14400 | 中国特供 |

### 4.3 同名不同规格（8 组显卡，共 16 独立条目）

5060 Ti 16G/8G、4060 Ti 16G/8G、9060 XT 16G/8G、RTX 3080 12G/10G、RTX 3060 12G/8G、GTX 1060 6G/3G、A770 16G/8G、A2000 12G/6G。
**型号名完全相同，必须靠显存区分。**

### 4.4 其他易踩坑

- ⚠️ **供电相数 ≠ 供电能力**：七彩虹 CVN B650 GAMING FROZEN 是 16 相但仅 55A（score 880），反而不如技嘉 B850M ELITE 的 14 相 80A（1120）。看相数会被骗
- ⚠️ **M.2 与显卡槽共享带宽**：微星 MAG B650 TOMAHAWK WIFI 装第 3 块 M.2 会让两条显卡槽都降 x2
- ⚠️ **Ryzen 8500G/8300G 装上会降速**：TUF B650M-PLUS WIFI、PRIME B650M-K 的 M.2 与显卡槽降速（战斧上 M.2_2 直接不可用）
- ⚠️ **E-ATX 需确认机箱**：5 款 E-ATX 主板（305×272mm），多数中塔只到 244mm
- ⚠️ **双限位机箱**：CH370、MACUBE 110、Archon 2、MX360 装前置冷排后显卡限长会再缩短
- ⚠️ **超高风冷**：NH-D15 G2 168mm 最高，追风者 D30/NH-D15/D14 均 165mm，标称 160mm 限高机箱装不下
- ⚠️ **超长电源**：振华 LEADEX VII 钛金 1600W 达 220mm（全库最长），海盗船 HX/AX 系列 200mm，仅全塔可装
- ⚠️ **DRAM-less 固态**：三星 990 EVO Plus / 致态 TiPlus7100+9100 / 金士顿 NV3 / 铠侠 SD10，大文件持续写入掉速，不建议系统盘
