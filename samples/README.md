# 真实配置单样本库（业务规格 §17.1）

用途：验证目录匹配率与规则输出质量（规格 §16.2），并决定国内人工目录的第一批收录名单。

## 收集方式

- 来源可以是：直播间/短视频配置单截图、电商整机页、朋友咨询的配置（需脱敏：去掉人名/昵称/订单号）。
- **保留原文的随意写法**（"散片""d4""迫击炮"），不规范写法正是测试价值所在。
- 每份一个 txt，格式不限，能看清"哪来的 + 报价 + 逐行配置"即可；截图直接给 AI 窗口转录也可以。

## 文件命名

`样本N_来源_日期.txt`，如 `样本1_直播间_2024-08.txt`。

## 目标

第一轮 ≥ 20 份（规格 §16.2）；凑够 3-5 份即可先跑一轮匹配率验证。
