# M34 工作台体验实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让新手在真实页面中轻松输入目标、看懂方案、继续表达修改并查询八类硬件。

**Architecture:** 保留现有 Next.js App Router 路由和 `/api/design`、`/api/catalog` 契约。页面从现有真实数据渲染；新增视觉与交互集中在 `src/ui/v2-workspace.css`，不改规则和持久化层。无模型时继续标明规则式生成。

**Tech Stack:** Next.js 16、React 19、TypeScript、现有 CSS tokens、Vitest、Playwright。

---

## 文件结构

- `src/app/page.tsx`：目标输入、快捷起步和最近项目。
- `src/app/design/[id]/page.tsx`：方案主结果、修订输入、证据和状态。
- `src/app/hardware/page.tsx`：面向新手的八类硬件检索与目录结果。
- `src/ui/components/nav-shell.tsx`：导航层级与当前页标识。
- `src/ui/v2-workspace.css`：上述页面与导航的响应式视觉系统。
- `src/app/globals.css`：导入新工作台样式。
- `tests/e2e/design.spec.ts`：输入、修订和依据操作回归。
- `tests/e2e/navigation.spec.ts`：硬件查询与窄屏导航回归。
