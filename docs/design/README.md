## 硬约束（任何页面通用）

1. 仪器橙 `#f4581c` 唯一主动作色；同屏主按钮唯一；
2. 语义色只表达真实状态（绿通过 / 琥珀注意 / 红阻断 / 灰未知）；
3. 数字、价格、版本、时间戳等宽 tabular-nums；
4. 禁止：深色主题、渐变、玻璃拟态、卡片套卡片、Agent 拟人、营销 hero；
5. 全站禁止横向滚动；`<900px` 左栏变顶部平铺菜单；
6. 诚实红线：估算标估算、未知标待补充、规则式不冒充 AI 搭配；
7. 每次改版：lint/typecheck/test/build/E2E 全绿 + 真实浏览器截图对照 `reference/` 验收。
