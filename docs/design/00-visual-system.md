# RigMate 视觉系统母版（M27）

> 当前视觉事实源：`src/ui/theme.css`、`src/app/globals.css`、`src/ui/finding-model.ts`。
> 主线由“仪器白 / 技术规格单”扩展为“仪器白 / 方案工作台”。

## 主视觉

- 暖白底：`#e8e6df`
- 面板白：`#f7f6f1` / raised `#fffefb`
- 发丝线：`#d6d3c8`；强线 `#b9b5a7`
- 墨黑：`#191b19`
- 次级文字：`#5c615b`；淡文字 `#979c93`
- 唯一强调色：仪器橙 `#f4581c`
- 数字、价格、预算、版本、时间：系统等宽字体 + `tabular-nums`

## 信息层级

1. **目标**：用户想完成什么。
2. **方案**：系统建议了什么。
3. **决策**：用户只需要选择什么。
4. **依据**：为什么这样建议，按需展开。
5. **编辑**：经验用户可以精确改什么。

首屏只展示前 3 层，依据和编辑渐进披露。

## 状态色

| 状态 | 色值 | 默认表达 |
|---|---|---|
| 可行 | `#2b8a3e` | 稳定、无需动作 |
| 冲突 | `#d64545` | 需要替换或确认 |
| 注意 | `#c77700` | 有取舍或风险 |
| 资料不足 | `#7c8288` | 需要补充或接受未知 |
| 不适用 | `#a6a89f` | 降透明度 |

状态色不用于装饰，不用综合评分替代具体状态。

## 反模板规则

1. 不使用满屏英文 micro-caps；
2. 不使用渐变、发光、玻璃拟态、bento 网格或圆角卡片墙；
3. 空状态使用一行安静文字；
4. Agent 活动使用短事件、时间戳和状态，不模拟长聊天记录；
5. 方案结果保持清晰呼吸感，避免表单和解释文字争夺 C 位；
6. 规则编号、字段名、来源链接和完整 Finding 默认隐藏；
7. 预算区间必须标记证据或经验估算状态；
8. 真实数据出图，不使用假型号、Lorem 或无来源数字。

## 页面节奏

- 目标入口：单一主输入，足够留白；
- 方案工作台：结果区优先，活动区次之，依据抽屉按需打开；
- 高级 DIY：可以恢复高密度规格表，但不影响普通用户主流程；
- 资料页：允许更高密度，服务高级用户和审计。

## 动效

只用于生成/校验事件逐步落位和完成状态提示，默认 150/450ms 两档，并尊重 `prefers-reduced-motion`。普通结果、表格和资料页不使用滚动光效。
