# RigMate 视觉系统母版（M21）

> 当前视觉事实源：`src/ui/theme.css`、`src/app/globals.css`、`src/ui/finding-model.ts`。
> 本文档覆盖旧 UI 文档中已被用户否定的深色蓝图方案；主线是**仪器白 / 技术规格单**。

## 主视觉

- 暖白底：`#e8e6df`
- 面板白：`#f7f6f1` / raised `#fffefb`
- 发丝线：`#d6d3c8`；强线 `#b9b5a7`
- 墨黑：`#191b19`
- 次级文字：`#5c615b`；淡文字 `#979c93`
- 唯一强调色：仪器橙 `#f4581c`
- 数字、价格、尺寸、规则号、时间：系统等宽字体 + `tabular-nums`，右对齐

## 语义色

| 状态 | 色值 | 视觉身份 |
|---|---|---|
| 通过 | `#2b8a3e` | 实线、稳态 |
| 阻断 | `#d64545` | 实线加粗、页边状态词 |
| 警告 | `#c77700` | 实线 |
| 待补充 | `#7c8288` | 虚线幽灵，不猜默认值 |
| 不适用 | `#a6a89f` | 降透明度 |

诊断顺序固定：阻断 → 待补充 → 警告 → 通过 → 不适用。

## 反模板规则

1. 不使用满屏英文 micro-caps；
2. 不使用渐变、发光、玻璃拟态、圆角卡片堆叠、bento 网格；
3. 空状态使用一行安静文字，不用图标 + 虚线框；
4. 类别使用下划线标签页，状态使用文字 + 小色点；
5. 预算未知件使用斜纹幽灵区，不按零元计入；
6. 动效只用于检查序列和全通过仪式，普通数据视图无滚动光效；
7. 事实数字必须来自规则、目录或快照，不在视觉稿里使用 Lorem/假型号。

## 基础网格

- 母版画布：1440 × 900
- 内容最大宽度：1240px，居中
- 顶部报头：76px
- 项目栏：64px
- 预算/数据行：56px
- 主区：左 1.35fr，右 1fr，间距 44px
- 规格表列：类型 42px / 型号 1fr / 价格 96px / 状态 64px / 操作
- 响应式断点：1120px、720px

## 画板使用方式

- SVG 是开发依据，PNG 是快速预览；
- 每张画板的同名 `.md` 记录映射目标、真实数据、token 和验收断言；
- 画板状态必须能对应现有 API/领域对象；没有实现的页面标为“规划参考”；
- 开发完成后，使用浏览器截图在同一 viewport 验收，不以 SVG 是否好看替代可操作页面验证。
