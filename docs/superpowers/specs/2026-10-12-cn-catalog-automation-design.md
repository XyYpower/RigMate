# 中国大陆主流硬件自动目录设计

## 目标

为 RigMate 增加一条不依赖人工逐条录入的中国大陆硬件目录同步链路。第一条垂直切片使用华硕中国/ROG 的公开产品索引和产品详情页，自动发现产品链接，解析中文型号、国行 MPN、关键兼容规格和公开价格，并产出可审计的目录快照。

## 边界

- 只访问公开页面和公开返回的数据；不使用登录态、验证码绕过、付费接口或反爬规避。
- 第一阶段实现 motherboard 详情页解析，保留同一适配器扩展到 CPU、GPU、RAM、storage、PSU、cooler、case 的接口。
- 解析失败、字段冲突或页面结构变化时生成失败报告，不写入猜测值。
- 价格作为可选快照字段，不参与规格事实判断；没有价格时目录仍可入库。
- 自动同步按必填字段完整度写入 `supported` 或 `partial`；自动来源不会直接写入 `verified`。

## 数据流

```text
中国大陆公开索引页
  -> 产品详情链接发现
  -> 公开详情页快照
  -> JSON-LD/SSR 规格提取
  -> 类别 schema 校验
  -> CanonicalProduct + provenance
  -> 自动目录导入
```

每次快照记录 URL、抓取时间、HTTP 状态、内容哈希、解析器版本和失败原因。产品身份优先使用页面 JSON-LD 的 SKU/MPN；无法确定身份时跳过正式目录写入并保留失败报告。

## 自动质量策略

- 页面标题、SKU、品牌和类别必须存在。
- 关键规格只接受明确数值或枚举文本；没有证据的字段保持缺失。
- 规格合并使用现有类别 schema，坏值拒绝整条产品。
- 同一 MPN 的重复链接合并，规格冲突保留冲突记录并将产品标记为 `conflicting`。
- 目录可用状态使用现有 `supported`，缺关键字段的产品保持 `partial`，不阻塞其他产品。

## 后续扩展

适配器接口保持 `discover(indexUrl)` 和 `parseProduct(url, html)` 两个边界。接入技嘉、微星、七彩虹等中国官网时只新增来源适配器，不改目录、规则和 Agent 层。REA 用于一次性观察动态页面的公开请求，生产同步使用固定适配器和定时任务。
