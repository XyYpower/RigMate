## 1. 统一页面结构

```
┌──────────┬──────────────────────────────────┬───────────┐
│ 左导航    │ 顶部工作栏（标题·修订输入·主动作）  │ 右上下文栏 │
│ 220px    ├──────────────────────────────────┤ 340px     │
│          │  主区（当前任务的面板化内容）        │ Agent进度  │
│          │                                  │ 需求/诊断  │
└──────────┴──────────────────────────────────┴───────────┘
```

- 左导航：开始配置 / 装机方案 / 硬件资料 / 我的方案 / 高级 DIY / 证据台账；当前项浅橙底 + 橙图标 + 右短竖线。
- 顶栏：方案标题 + 状态徽章 | 自然语言修订输入（方案页）| 全局主动作。顶栏唯一橙主按钮。
- 右栏上半：Agent 处理进度时间线；下半：方案页=你的需求摘要 + 待确认；DIY 页=兼容性诊断。

## 2. 页面职责

| 路由 | 导航项 | 主区内容 | 右栏下半 |
|---|---|---|---|
| `/` | 开始配置 | 自然语言输入 + 预算快捷 + 示例 + 最近方案 | Agent 说明 + 最近目标摘要 |
| `/design/[id]` | 装机方案 | 推荐摘要卡、配置清单表、决策条、接受/调整/DIY | 需求摘要 + 待确认 |
| `/hardware` | 硬件资料 | 八类硬件用途介绍 + 目录检索（来源/缺失字段） | — |
| `/projects` | 我的方案 | 按生命周期分组：生成中/待确认/可继续 DIY/已完成 | — |
| `/diy` | 高级 DIY | 八类子导航 + 规格编辑 + 机箱/显卡尺寸预览 | 兼容性诊断（阻断→待补充→通过） |
| `/evidence` | 证据台账 | 价格证据录入与台账 | — |
| `/builds/[id]/report` | —（次级） | 报告文档 | — |

## 3. 状态与响应式

- 状态全集：loading / ready / attention / conflict / unknown / accepted / error（呈现方式见 DESIGN.md §7）。
- `≥1200px` 三栏；`900-1199px` 右栏并入主区底；`<900px` 左栏变顶部平铺菜单、单列排列。全站无横向滚动。

## 4. 事实边界（不变）

精确规格、价格、尺寸、兼容性只来自目录、证据与规则 API；组件不猜值。模型只理解目标/修订意图；方案版本不可变、可回看；正式 Build 仅由用户接受创建。
